## What the input figures DO NOT establish

1. **No measured centroid-shift significance** is available from visual inspection alone; a large absolute centroid offset from catalog coordinates does not necessarily mean the transit is off target. Need actual paired event coordinates, pixel scale, and uncertainty.
2. **No new planetary confirmation or validated binary**. A 2025 catalog classification and a 2026 neural score may be in tension because ephemeris matching, processing version, stellar multiplicity, or label provenance changed.
3. **No evidence our code currently outperforms or changes NASA ExoMiner++**. We ran NASA's own input plotting exactly as documented, with the original model unchanged.
4. The diagnostic cases are **chosen after viewing errors**, so any subsequent tuning on these same five cannot also be tested on them as if they were new holdout stars.

## Focused next engineering experiment

Build a **version-locked event-local centroid-displacement statistic** from original **TESS SPOC time-series centroid fields**, matching the official TCE predicted epoch, duration and period. Subtract a local (same event) pre/post baseline centroid, propagate missing/flagged cadences and event-to-event scatter; contrast with alternative `P/2` and `2P` ephemerides, while preserving the unaltered original NASA scores. Explicitly separate the **absolute centroid-to-catalog offset** already plotted by NASA from the **transit-phase-dependent centroid change** to be measured. A signal is **not** new by merely having a centroid feature, because NASA ExoMiner already includes centroid and pixel-difference branches. **A genuinely new improvement requires a further fixed, non-post-hoc source cohort with same-source predictions and a common precision/false-alarm budget**, and documented train/test exclusions.
