# November 25 controlled centroid experiment: specification before execution

Purpose: explain when subtracting a reference star's pointing signal can improve or degrade source identification, supplementing (not replacing) the actual Kepler and TESS work. This is a synthetic measurement model, not NASA observations or a validated instrument pipeline.

- One-dimensional, unresolved blend: target at 0 pixels, neighbor at 1 pixel; unocculted fluxes 1 and 0.25. Equal observed total-light dip of 1,000 ppm, with all lost flux attributed to either target or neighbor. Compute true in/out centroid change exactly using the flux-weighted mean.
- One simulated event consists of 12 in-transit and 24 out-of-transit measurements. Instrument pointing is represented by a common random in-minus-out displacement with Gaussian SD 0, 0.0005, 0.002 or 0.008 pixels. This is an idealized window-level model, not a mission-calibrated jitter distribution.
- Science centroid has independent Gaussian per-measurement noise SD 0.001 pixels; reference centroid has independent Gaussian per-measurement noise SD 0.0005, 0.002 or 0.006 pixels. In/out mean differences have SD equal to the per-measurement SD times sqrt(1/12 + 1/24). Science and reference see exactly the same pointing displacement. Assume known direction of the neighbor, no other sources, no aperture truncation or reference-star variability.
- Use NumPy default_rng seed 1260025. Generate 1,000 target and 1,000 neighbor events with the same independent standard-normal draws across all 12 settings. Within every setting compare identical events with and without reference subtraction.
- Frozen classification rule: positive centroid shift predicts target dimming; negative shift predicts neighbor dimming. No fitting or threshold tuning. Compute raw and corrected classification counts, class-specific recall, balanced accuracy (equal class counts), paired wins/losses, and centroid shift RMSE relative to exact true shift in pixels. Report all 12 conditions, including negative results. Save code, numeric CSV, and a figure.
- Hypothesis: correction can improve source direction when common displacement exceeds reference measurement error; it can degrade direction and RMSE if the instrument is already steady or the reference is noisy. This tests an idealized mechanism, not real-world mission performance or discovery of planets.
